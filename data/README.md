# GandhiGPT Training Dataset

## Original Dataset

The raw Gandhi text data used in this project was obtained from:

**Gandhi Dataset:**  
https://github.com/AbelTheGeorge/Gandhi-Dataset

The dataset is based on *The Collected Works of Mahatma Gandhi (Electronic Book)*, New Delhi, Publications Division, Government of India, 1999, 98 volumes.

## Preprocessing

The original data was cleaned and prepared for character-level language model training.

The resulting cleaned text file was named `gandhi_clean.txt`.

## Dataset Usage

The dataset was used for educational and experimental purposes to train a small character-level Transformer.

Please refer to the original dataset repository for its source information and usage terms. The source repository specifies non-commercial research and educational use.
